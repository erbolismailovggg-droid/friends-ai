FRIENDS AI / жеке достар альбомы

Іске қосу:
1. ZIP файлын ашыңыз.
2. index.html файлын браузерде ашыңыз.

Интернетке жариялау:
- Бұл статикалық сайт. GitHub Pages немесе басқа статикалық хостингке жариялауға болады.
- Репозиторийге index.html және assets папкасын бірге жүктеңіз.
- GitHub-та Settings -> Pages -> Deploy from a branch -> main / root таңдаңыз.
- Хостинг сайттың URL мекенжайын береді.

Ескерту:
- Сайттың сілтемесі барлық адамға қолжетімді болсын десеңіз, жария хостинг қажет.
- Тегін хостинг мәңгілік қолжетімділікке кепілдік бермейді; домен мен хостингті мерзімінде жаңарту керек.
- Фотодағы достардың келісімін алып барып жариялаңыз.
- Instagram логиндері берілген күйінде енгізілді.
